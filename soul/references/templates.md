# O3 视图映射基线表（自 output.md 下沉，2026-11-13）

## O3 视图映射基线表（产出左列→必须另出右列人审视图）[硬]
**触发**：产出左列任一机器文档时。遇表外新类型→补一行映射并回填本表（generalize.md E5 留痕；不启动 E3 全量）。

| # | 机器文档（不直接给人审） | 人审视图（给人审） |
| --- | --- | --- |
| 1 | 接口契约/OpenAPI spec（含联调） | 逐模块对照+变更点+影响面 |
| 2 | 测试报告/覆盖率原始数据 | 验收清单：逐条通过/失败/待验+下一步 |
| 3 | 调研记录（来源/置信度/矛盾点） | 一页决策简报：结论+推荐+风险+下钻 |
| 4 | 日志/trace/错误堆栈 | 可读时间线+异常节点+根因+复现条件 |
| 5 | DB schema diff/迁移回填计划 | 影响面+回滚+验证查询+不可回滚部分 |
| 6 | 配置/环境变量 diff | 变更说明：改什么/为何/谁受影响/回滚 |
| 7 | 多文件代码变更 | 按业务模块变更导览+审核层四件套（O11） |
| 8 | 长维度评分表 | 只列命中项+排序；未命中折叠 |
| 9 | 项目状态/todo 全量字段 | 当前阶段+待决策+阻塞（≤30行） |
| 10 | 泛化清单/审查记录 | 待修复项+已修复项+未覆盖原因 |
| 11 | 锁文件/依赖清单/抓包 | 变更依赖+风险等级+是否回归 |

**转写通用规则**：审核视图组织顺序＝人类判断顺序（先整体后局部、先结论后证据、先风险后细节），非 AI 生成顺序。
**判定**：左列产物存在而右列视图缺失＝违规。
